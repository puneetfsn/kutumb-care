About

Kutumb Care is a 100% offline family emergency checklist for India. It helps your people find Aadhaar, bank nominees, LIC policies, EPF / UAN, property deeds and trusted contacts — without ever storing passwords. This web version stores everything only in this browser on this device; clearing browser data erases it, so keep a JSON backup or printed dossier.
